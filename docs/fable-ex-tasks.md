    Use Fable 5 for the whole ingest arc: profile source files, define a rubric, split parser/workbook/runtime checks, verify candidate output, and leave lessons in STATE.md.

2. Workbook source-of-truth migrations
    Good for multi-pass cleanup where workbook rows, generator behavior, artifacts, tests, and docs all need to stay aligned.

3. Large configurator/UI direction
    Especially visualizer-first or major form UX work where it should use screenshots, compare against a goal, and have an independent verifier check behavior and visuals.

4. Cross-model regression hardening
    When Stingray, Grand Sport, Z06, registry, generated contracts, and runtime tests all interact, Fable 5 can coordinate the investigation instead of one agent tunneling on a single failure.

5. Audit/cleanup programs
    Route normalization, stale artifact cleanup, docs/archive hygiene, obsolete workflow retirement, and “make the repo less confusing over time” are strong Fable 5 jobs.

6. Recurring improvement routines
    Weekly/monthly evals: run known gates, inspect failures, classify drift, update loop memory, and propose the next narrow pass.
