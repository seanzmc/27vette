One main canvas

The visualizer owns the first impression. Controls sit around it, not inside stacked cards.

One progress root

The right rail carries colored status, requiredness, and sequence. No extra progress widgets competing with it.

Mode changes by content

Exterior and interior are visual. Performance and accessories can switch to a list because visual feedback adds less value there.

Messages stay local

Unavailable, auto-added, and newly available messages appear beside the affected choice, not in another summary box.

Core Direction Choice

This is the next decision I would lock before writing a spec.

Chevy-like visual-first flow

Use the visualizer as the main surface for vehicle/exterior/interior steps, with right-side progression and a separate non-visual options phase.

Current form plus visual panel

Keep the current step layout more intact and add the visualizer as a prominent panel. Lower disruption, but more risk of crowding.
