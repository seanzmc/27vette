# 27vette ingest docs

This folder owns the current schema and raw order-guide ingest planning docs.

Raw GM order-guide ingest is an edge workflow, not routine maintenance. Use it only for:

- adding a model that is not already in the form; or
- performing a broad GM/order-guide refresh across existing models.

Routine corrections belong in canonical workbook source sheets, followed by normal regeneration and gates.

## Production target division of responsibilities

Milestone 0 writer safety through Milestone 2.3 target-evidence reconciliation are implemented and independently verified. Milestones 2.4/2.4.1 also passed exact-current independent prerequisite verification. Milestone 3 mechanical `pass-c-3` projection and temporary deployment proof are implemented and parent-verified against run `20260717-091317-470292`; independent final verification is in progress. The approved plan remains dry-run evidence only: no live workbook write, publication, promotion, deployment, or dealer authority is implied.

For the current Grand Sport X/ZR1/ZR1X intake profile, the script owns every derivable canonical row: scoped source profiling, option/OVS extraction, exact joins, stable target identity, direction-aware relationships, comparator-corroborated rule/group proposals, and mechanical workbook projection. This is a targeted pre-production module, not yet a generally model-agnostic ingest engine.

The user owns only exceptions: facts not derivable from target raw evidence and canonical workbook metadata, comparator-backed proposals that still need target confirmation, genuine conflicts, and explicit allowed deferrals.
