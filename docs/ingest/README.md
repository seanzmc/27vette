# 27vette ingest docs

This folder owns the current schema and raw order-guide ingest planning docs.

Raw GM order-guide ingest is an edge workflow, not routine maintenance. Use it only for:

- adding a model that is not already in the form; or
- performing a broad GM/order-guide refresh across existing models.

Routine corrections belong in canonical workbook source sheets, followed by normal regeneration and gates.

## Production target division of responsibilities

Milestone 0 writer safety, Milestone 1's read-only headless compiler, Milestone 2's compiler/typed-exception browser flow, and Milestone 2.1's compiler-consumer closure are implemented and independently verified. New runs no longer continue through the historical broad review lanes after model selection. The browser exposes only compiler-complete, finite typed actions; unresolved source facts and unimplemented compiler projections remain actionless blockers. The current all-target manifest is not ready, so plan projection remains Milestone 3 and is not approved.

In the production target, the script owns every derivable canonical row: source profiling, option/OVS extraction, exact joins, stable target identity, direction-aware relationships, comparator-corroborated rule/group proposals, and mechanical workbook projection.

The user owns only exceptions: facts not derivable from target raw evidence and canonical workbook metadata, comparator-backed proposals that still need target confirmation, genuine conflicts, and explicit allowed deferrals.
