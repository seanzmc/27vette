Performance Handling

This is the one place where the flow needs a clear rule because it mixes visual and non-visual choices.

Recommended: one Performance step, mixed controls

Keep Performance as one step. Use the visualizer stage when the active subgroup affects appearance, then switch the same workspace to compact cards for purely mechanical choices. The rail stays simple.

Split Performance into Visual and Mechanical

Make spoiler/exhaust/engine appearance one visual phase, and mechanical/suspension a separate card-list phase. Clearer internally, but adds another top-level stop.
